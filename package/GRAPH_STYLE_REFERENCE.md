# Graph Style Reference

All figures in this package are generated directly by
`paper_tools/generate_publication_figures.py`, the user-honed DeepSeek publication generator.
No replacement plotting layer is used.

The generator was run against the authoritative PARAM Shakti snapshot and accepted Kaggle
artifacts. Ten of its eleven fresh PNGs match the corresponding graphs in
`A_Trustless__Fault_Tolerant_Architecture_for_Distributed_LLM_Training_on_Untrusted_Networks.zip`
byte-for-byte. Figure 10 is intentionally different because its values were corrected from
test-curve maxima to final-epoch results. The correction preserves the generator's styling,
layout, typography, colours, legends, and export settings.
